## 已知问题及未覆盖项

- 中文 UTF-8 数据恰好在多字节字符中间拆包时，Qt 当前文本解码逻辑可能损坏字符。
- 非法 HEX 字符被过滤的处理方式需要更严格的错误提示。
- 串口异常拔出、长时间接收缓存、日志写入失败恢复等边界未完全测试。
- GDB / OpenOCD 已验证基础断点与单步，仍出现 esp_symbols table size (16) is not valid 警告；FreeRTOS 完整任务级调试未验收。
- 当前没有覆盖多个波特率、全部串口转换芯片、所有 MCU 及超过数小时的持续运行。

不要将上述未测项目写成已通过的能力或 CI 状态。

## 复现方式

参见 [ESP32-S3 示例](../examples/esp32s3-usb-echo/README.md)。运行字节回显测试需要 Python 3 和 pyserial，并应确保 COM 端口未被其他程序占用。

本项目的原始本地测试包含特定电脑的绝对路径与调试日志；仓库公开内容保留可移植示例，不上传个人电脑缓存、设备特征标识或本机生成文件。
