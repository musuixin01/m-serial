# M_SERIAL · 开发路线

[回到首页](../README.md) · [架构](ARCHITECTURE.md) · [验证记录](VALIDATION.md)

现有 Qt Widgets 程序和 Windows + ESP32-S3 回显功能已经通过实测。以下是后续规划，未完成的工作不得在 README 中标为现有能力。

## P0 · 串口通信可靠性

- [ ] 连接串口错误信号，处理设备拔插、资源被占用与错误恢复。
- [ ] 自动发送随端口状态安全停止，避免关闭串口后重复触发。
- [ ] 用可增量解码的文本接收缓冲处理跨块 UTF-8。
- [ ] 严格验证 HEX 输入，拒绝非法数据并指出错误位置。
- [ ] 为接收区设置可配置的缓存上限。
- [ ] 对 send/write 失败和部分写入补充错误处理。

验收：异常拔插、错误输入、连续传输、恢复连接的测试全部有真实记录。

## P1 · 平台和测试

- [ ] 从 MainWindow 中抽出可独立测试的 SerialCore，不改变原有通信协议。
- [ ] 在独立干净环境验证 Windows Release 打包。
- [ ] Linux x64 运行与串口功能回归。
- [ ] RK3568 ARM64 重新编译部署及同一测试矩阵。
- [ ] 扩展 ESP32-S3 测试用例，包括分片、多波特率、持续运行与错误注入。

验收：逐平台形成构建版本、硬件连接、测试结果和已知问题记录。

## P2 · 面向真实开发的体验

- [ ] 用户可保存多套串口参数。
- [ ] 接收数据检索、过滤和分段日志。
- [ ] 更清晰的状态与收发计数视图。
- [ ] 统一桌面视觉语言和键盘可用性。
- [ ] 可选协议解析与波形功能，须先确定明确用途。

这些均为候选方向，不应通过添加无效按钮或演示数据冒充实现。
